# Fontes usadas neste projeto

Todas as fontes abaixo são distribuídas sob a **SIL Open Font License 1.1**, que
permite uso, cópia e redistribuição (inclusive em projetos comerciais), desde
que a própria fonte não seja vendida sozinha. Os arquivos `.woff2` foram
baixados do [Fontsource](https://fontsource.org/) (que empacota as fontes do
Google Fonts para self-hosting) e ficam neste diretório para o site funcionar
offline, sem depender de um CDN externo.

Subconjunto usado: **latin** (cobre acentos do português: á, ã, ç, é, etc.).
