Mercado Livre (API oficial)

O Mercado Livre bloqueia a leitura das páginas por programas. Em vez de tentar burlar isso, o site usa a API oficial: você autoriza uma aplicação sua e os preços passam a vir por ela.

{% if not ml_credentials %}

Aplicação ainda não configurada.

  1. Entre em developers.mercadolivre.com.br → Minhas aplicações → Criar aplicação.
  2. Em "URI de redirect", use {{ url_for('mercadolivre_callback', _external=True) }}. Se o Mercado Livre exigir um endereço https, ponha qualquer um seu (ex.: https://exemplo.com/callback) e depois use a opção "colar o código" aqui embaixo.
  3. Copie o App ID e a Secret Key para o .env: 
    MONITOR_ML_CLIENT_ID=seu-app-id
MONITOR_ML_CLIENT_SECRET=sua-secret-key
MONITOR_ML_REDIRECT_URI={{ url_for('mercadolivre_callback', _external=True) }}
  4. Rode o servidor de novo e volte aqui.

Capturar preço do navegador

Para lojas que bloqueiam a leitura automática (Mercado Livre, Magazine Luiza). Você abre a página da loja normalmente e o favorito envia para cá o preço que a página já está mostrando.

  1. Mostre a barra de favoritos do navegador (Ctrl + Shift + B).
  2. Arraste o botão abaixo até a barra de favoritos.
  3. Abra a página do produto na loja e clique no favorito Capturar preço.
  4. Na aba que abrir, confira os dados e clique em Salvar preço.
{{ icon("tag", 16) }}Capturar preço

Nada é salvo sem a sua confirmação. O favorito só lê a página que você já tem aberta.
